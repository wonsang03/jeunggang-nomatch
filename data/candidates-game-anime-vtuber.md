# 곡 후보 목록 — 게임 · 애니 · 버튜버 (각 50곡)

유튜브 링크·구간은 **아직 비어 있음**. 곡 선정만 한 단계.
기존 DB(게임 59 · 애니 105 · 버튜버 55)와 전부 대조해서 **중복 제외**했음.

`확인` 칸의 `△` = 내가 100% 확신하지 못하는 항목. 링크 채울 때 제목/아티스트를 한 번 더 봐줘.

## 슬롯 규칙

| 장르 | 슬롯 1 | 슬롯 2 |
|---|---|---|
| 애니 | `애니 제목` | `노래 제목` — 이 2개로 고정 |
| 게임 | `게임 이름` | `노래 제목` / `맵` / `보스 이름` — **답에 맞는 라벨을 행마다 따라감** |
| 버튜버 | `노래 제목` | 오리지널이면 `가수`, 커버곡이면 `커버` |

## 제외한 곡 (기존 DB에 이미 있어서)

- 우마뾰이 전설 — 애니 장르에 있음 (이세돌 커버본은 중복)
- Snow halation — 애니(러브라이브) + 버튜버(허니즈) 양쪽에 있음
- 장난기 기능 — 버튜버(에스더 커버)에 있음
- 세계는 사랑에 빠져있어 — 애니(아오하라이드)에 있음
- Daybreak Frontline — 버튜버(비챤 · 텐코 시부키) 두 건 있음
- 봄꿈 — 버튜버(네네코 마시로)에 있음
- 마음악보 — 버튜버(Universe) 2nd Single, 이미 DB에 있음
- STAR TRAIL — 버튜버(스텔라이브)에 있음
- unravel — 도쿄구울 항목이 곡 슬롯 없이 들어가 있어서, 이미 unravel일 가능성이 커 제외
- 실루엣 — 나루토 "가수=카나분" 항목이 이미 있어서 제외
