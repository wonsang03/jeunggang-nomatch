## 원칙

- **관리(git pull·빌드·실행·재시작)는 전부 아마존 브라우저 SSH 터미널에서** 한다. (보안상)

## 단계

### 0. (PC) 로컬 코드 깃 최신화
아직 커밋/푸시 안 했다면:
```powershell
cd "C:\Users\ssw86\OneDrive\바탕 화면\증강노맞"
git add -A
git commit -m "변경 내용"
git push origin main
```

### 1. Lightsail 콘솔에서 인스턴스 Start → Public IPv4 확인

### 2. (PC PowerShell) DB를 서버로 올리기
DB 파일이 물려 있으면 깨질 수 있으니 서버를 먼저 멈춘 뒤 업로드한다.
```powershell
# 서버 잠깐 정지
ssh -i "$env:USERPROFILE\Downloads\LightsailDefaultKey-ap-northeast-2.pem" admin@<IP> "pm2 stop jeunggang"

# DB 업로드
scp -i "$env:USERPROFILE\Downloads\LightsailDefaultKey-ap-northeast-2.pem" `
"C:\Users\ssw86\OneDrive\바탕 화면\증강노맞\server\prisma\dev.db" `
admin@<IP>:~/jeunggang-nomatch/server/prisma/dev.db
```

### 3. (아마존 브라우저 SSH 터미널) 최신화 · 빌드 · 실행
Lightsail 콘솔 → 인스턴스 → **Connect using SSH** 버튼 → 뜨는 검은 창에 통째로 붙여넣기:
```bash
cd ~/jeunggang-nomatch
git pull origin main

cd server
npm i
npx prisma generate
npm run build

cd ../web
npm i
NODE_OPTIONS=--max-old-space-size=768 npm run build
rm -rf ~/jeunggang-nomatch/server/public
mkdir -p ~/jeunggang-nomatch/server/public
cp -r dist/. ~/jeunggang-nomatch/server/public/

cd ~/jeunggang-nomatch/server
pm2 restart jeunggang || pm2 start npm --name jeunggang -- run start
pm2 save

# 점검
pm2 status
curl -s http://127.0.0.1:4000/health; echo
```

### 4. HTTPS 인증서 (IP가 바뀌었거나 "주의 요함"이 뜰 때)
인증서 발급만 되고 Nginx 연결이 실패하는 경우가 많다. 아래를 통째로 실행한다.
```bash
PUBLIC_IP=$(curl -s https://checkip.amazonaws.com | tr -d '\n')
DOMAIN="${PUBLIC_IP}.sslip.io"
echo "도메인: https://$DOMAIN"

# 인증서 없으면 발급
if [ ! -f "/etc/letsencrypt/live/$DOMAIN/fullchain.pem" ]; then
  sudo certbot certonly --nginx -d "$DOMAIN" --non-interactive --agree-tos --register-unsafely-without-email || \
  sudo certbot certonly --webroot -w /var/www/html -d "$DOMAIN" --non-interactive --agree-tos --register-unsafely-without-email
fi

# Nginx에 새 도메인 + 인증서 직접 연결
sudo tee /etc/nginx/sites-available/jeunggang >/dev/null <<EOF
map \$http_upgrade \$connection_upgrade {
  default upgrade;
  '' close;
}

server {
  server_name $DOMAIN;

  location / {
    proxy_pass http://127.0.0.1:4000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade \$http_upgrade;
    proxy_set_header Connection \$connection_upgrade;
    proxy_set_header Host \$host;
    proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto \$scheme;
    proxy_read_timeout 86400;
    proxy_send_timeout 86400;
    proxy_buffering off;
    proxy_request_buffering off;
    proxy_cache off;
    tcp_nodelay on;
  }

  listen 443 ssl;
  ssl_certificate /etc/letsencrypt/live/$DOMAIN/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/$DOMAIN/privkey.pem;
  include /etc/letsencrypt/options-ssl-nginx.conf;
  ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;
}

server {
  listen 80;
  server_name $DOMAIN;
  return 301 https://\$host\$request_uri;
}
EOF

sudo ln -sf /etc/nginx/sites-available/jeunggang /etc/nginx/sites-enabled/jeunggang
sudo nginx -t
sudo systemctl reload nginx
curl -s "https://$DOMAIN/health"; echo
```

### 5. 접속 확인
`https://<IP>.sslip.io` 접속.
`/health`가 `{"ok":true}` 나오면 정상.

## 서버 끌 때
아마존 브라우저 터미널 또는 PC SSH에서:
```bash
pm2 stop jeunggang
pm2 save
```
그 다음 Lightsail 콘솔에서 인스턴스 **Stop**. (요금 완전 종료하려면 스냅샷 후 인스턴스 삭제)

## 자주 나는 문제
- `Could not resolve hostname 서버ip` → `<IP>`를 실제 숫자로 안 바꿈.
- 22번 포트 접속 안 됨 → 인스턴스가 꺼져 있거나 IP가 바뀜. 콘솔에서 Start 후 새 IP 사용.
- 웹 빌드 중 메모리 부족 → 스왑 2GB 설정 확인, `NODE_OPTIONS=--max-old-space-size=768` 유지.
- Nginx 80 포트 충돌(Apache) → `sudo systemctl disable --now apache2` 후 `sudo systemctl restart nginx`.
